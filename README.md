# TryHackMe Cyber Security 101

This repository documents my hands-on learning and practical experience while completing the TryHackMe Cyber Security 101 learning path.

My goal is not simply to complete the learning path, but to strengthen my practical cybersecurity skills and document what I learn along the way. This includes technical concepts, commands and tools I practise, challenges I encounter, and how the skills relate to real-world cybersecurity.

## 🎯 Learning Objectives

Through this learning path, I aim to:

- Strengthen my understanding of offensive and defensive security
- Develop greater confidence working with Linux environments
- Improve my networking and security fundamentals
- Gain hands-on experience with cybersecurity tools and techniques
- Develop my understanding of security monitoring and incident response
- Connect theoretical cybersecurity concepts with practical exercises

## 🛠️ Practical Approach

Rather than documenting answers to TryHackMe challenges, this repository focuses on my personal learning and practical development.

For each major topic, I will document:

- Key concepts I learned
- Commands and tools I practised
- Practical exercises I completed
- Challenges and troubleshooting
- Cybersecurity relevance
- Key takeaways from the exercises
